🛠️ 系统安装优化

⏩ 安装系统跳过网络连接

适用场景: 全新安装Windows时跳过强制联网要求，节省时间并保护隐私

操作步骤:

  1. 在系统安装界面的网络连接页面
  2. 按下 SHIFT + F10 打开命令提示符
  3. 输入以下命令并回车：
1

oobe\bypassnro.cmd

效果: 系统将重启并出现"我没有Internet连接"选项，可以跳过微软账户登录 ✅

替代方法: 在需要输入微软账户的界面，输入no@thankyou.com并任意密码，也会跳过联网要求

🛡️ 隐私与安全设置

🔒 彻底关闭实时保护

方法一: 通过组策略编辑器 (Windows专业版/企业版)

1
2

# 打开组策略编辑器
gpedit.msc

导航路径:

  • 计算机配置 → 管理模板 → Windows组件 → Microsoft Defender防病毒 → 实时保护
  • 启用 关闭实时保护

方法二: 通过注册表 (所有Windows版本)

1
2
3
4
5

# 临时禁用实时保护
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows Defender" /v "DisableAntiSpyware" /t REG_DWORD /d 1 /f

# 重启后生效
shutdown /r /t 0

🔕 关闭安全中心通知

操作路径:

  • 组策略编辑器 → 计算机配置 → 管理模板 → Windows组件 → Windows安全中心 → 通知
  • 启用 隐藏所有通知

🚫 禁用遥测和数据收集 

1
2
3
4
5

# 禁用诊断数据收集
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v "AllowTelemetry" /t REG_DWORD /d 0 /f

# 禁用广告ID
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AdvertisingInfo" /v "DisabledByGroupPolicy" /t REG_DWORD /d 1 /f

⚠️ 注意事项

🔴 重要警告

  1. 修改风险: 注册表修改有风险，操作前请备份

    1
2

    # 导出当前注册表配置
reg export HKCU\Software\Microsoft\Windows C:\regbackup.reg

  2. 系统兼容性: 某些命令仅适用于特定Windows版本

    • gpedit.msc 仅限专业版/企业版
    • winget 需要安装App Installer

  3. 安全考虑: 禁用安全功能可能增加系统风险

    • 建议安装第三方安全软件替代Windows Defender
    • 定期手动检查更新以确保安全

✅ 最佳实践

  1. 创建还原点: 重大修改前创建系统还原点

    1
2

    # 创建系统还原点
wmic.exe /Namespace:\\root\default Path SystemRestore Call CreateRestorePoint "Before Optimization", 100, 7

  2. 逐步测试: 每次只修改一个设置，测试稳定性后再进行下一个

  3. 文档记录: 记录所有修改，便于故障排除和恢复

🆘 遇到问题怎么办？

  1. 系统还原: 使用之前创建的系统还原点恢复
  2. 安全模式: 在安全模式下撤销更改
  3. 重置系统: 使用系统设置中的"重置此电脑"功能

💡 专业提示: 在进行系统优化时，建议先创建一个系统还原点，并逐个测试优化效果。不同的硬件配置和使用场景可能需要不同的优化方案，请根据实际需求选择适合的命令。

🎯 记住: 优化是一个持续的过程，定期检查和调整设置可以获得最佳体验。
